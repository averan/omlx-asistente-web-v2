Cómo funciona

Pensado para trabajar en local

Privacidad total

Tus preguntas nunca salen de tu equipo. El modelo corre en tu Mac y responde desde ahí.

Apple Silicon

oMLX aprovecha la memoria unificada y la GPU de los chips M para generar texto con fluidez.

Respuestas en streaming

El texto aparece palabra a palabra, igual que en los asistentes en la nube.

API compatible

Habla el mismo idioma que la API de OpenAI, así que cualquier herramienta puede conectarse.

Cómo funciona

  1. 1

    Arranca oMLX

    El servidor carga un modelo MLX y expone una API en localhost:8000.

  2. 2

    Abre el asistente

    Pulsa el botón de la esquina inferior derecha. Detecta solo qué modelo está cargado.

  3. 3

    Pregunta lo que quieras

    La conversación se guarda en tu navegador para que puedas retomarla después.

Preguntas frecuentes

¿Necesito conexión a internet?

No para conversar: el modelo se ejecuta en tu equipo. Solo hace falta que oMLX esté en marcha.

¿Qué modelo usa el asistente?

El que tengas cargado en oMLX en ese momento. Si no hay ninguno cargado, usa el modelo por defecto del servidor.

¿Dónde se guardan mis conversaciones?

Solo en el almacenamiento local de este navegador. Puedes borrarlas con «Nueva conversación».
